# 전역 인증자 페이지 설계

날짜: 2026-08-28
상태: 승인됨 (승우님)

## 목적

`applicants.prior_certs`(jsonb 배열)에 통합 적재된 AI챔피언 공식 인증자 명단(2025년 541건 + 2026년 909건)을
한 화면에서 조회·필터·엑셀 다운로드할 수 있는 전역 페이지를 추가한다.
현재는 선발 화면의 `PriorCertsChips`로 지원자별 개별 표시만 가능하고 전체 조망 화면이 없다.

## 결정 사항

- **위치**: 전역 메뉴 `/dashboard/certified` (인증은 연도·기수를 넘나드는 마스터 데이터)
- **행 단위**: 인증 건 단위 (prior_certs 항목 1건 = 1행, ~1,450행). 같은 사람이 그린+블루 보유 시 여러 행
- **PII**: 연락처·이메일은 화면 미표시, 엑셀 export에만 포함
- **접근 방식**: 서버 조회 + 클라이언트 필터 (A안). RPC·서버 페이지네이션 없음 —
  1,450행 규모라 전체 조회 후 클라이언트 사이드 검색·필터·정렬로 충분 (CLAUDE.md의 JS 집계 관례)

## 구성

### 라우트·네비게이션
- `src/app/dashboard/certified/page.tsx` (Server Component)
- `src/app/dashboard/certified/_components/certified-table.tsx` (Client Component)
- `app-sidebar.tsx` 전역 섹션에 "인증자" 메뉴 추가 (지원자 마스터 인근)

### 데이터 흐름
- `createAdminClient()`로 `prior_certs != '[]'`인 applicants 조회 (이름·기관·부서·직급·prior_certs)
- 서버에서 인증 건 단위 flatten: 연도·인증명(cert_name)·트랙·유형(kind)·회차·인증번호·이름·기관·부서·직급
- 기본 정렬: 연도 내림차순 → 블루 먼저 → 인증번호 오름차순 (2025 종합관리 관례)

### 화면
- 상단 요약 카드: 연도×트랙별 건수 + 총계. 이월분(2026-BC0001~0005)은 2026에 포함
- 테이블: 검색(이름·기관), 필터(연도/트랙/유형), 인증번호·연도 정렬
- 이름 클릭 → 지원자 마스터 상세 연결
- 테스트 학생 제외 규칙은 해당 없음 (인증자는 공식 명단 기반)

### 엑셀 export
- `/api/certified/export` 라우트 — 적용된 필터를 쿼리 파라미터로 수신
- 종합관리 xlsx 13컬럼: 인증명·인증유형·구분·이름·기관분류·기관·부서명·직급·직렬·연락처·이메일·인증번호·인증일자
- 인증일자는 prior_certs에 없으므로 빈 값. 기존 export 라우트의 라이브러리 패턴 재사용
